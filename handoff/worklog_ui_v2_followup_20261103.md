## 1. 정렬 (원인과 패치)
- 원인: iPhone Safari는 `input type=date`의 값을 가운데 정렬하고 높이/패딩을 무시함.
- 패치(globals.css): `appearance:none`, `::-webkit-date-and-time-value{text-align:left}`, 달력 아이콘 오른쪽 끝.
- 확인: iOS 시뮬레이터(iPhone 17, iOS 26.5) Safari에서 왼쪽 정렬·세로 가운데 확인 (`screens/v2_input_*_iphone_safari.png`).
- 내역 줄: 수정/삭제 아이콘이 메타 줄 끝에 끼어 줄바꿈 시 어긋나던 것 → 아이콘 제거, 줄 전체를 누르면 수정 시트.
- 숫자 입력 스핀 버튼 숨김, 포커스 시 테두리 강조.

## 2. 이모지 (절제)
- 카드: 카드색을 옅게 깐 둥근 사각형 안에 카드 이모지(iOS 앱 아이콘 느낌). 입력·수정·내역 필터·내역 줄·실적·리포트에서 같은 표시.
- 국민 쿠팡와우 아이콘 🛒 → 🚀 (식비 카테고리 🛒와 겹쳐서 헷갈림. 쿠팡 로켓배송 연상).
- 섹션 제목에만 하나씩: 💡 카드 가이드, 🏦 가게통장, 📊 지난달 대비, 💳 카드별 실적, 🏷️ 카테고리, 🎯 우선순위, ✨ 혜택 달성.

## 4. iOS 조작감
- 모든 버튼 누름 반응(살짝 작아짐), 더블탭 확대 지연 제거(`touch-action: manipulation`).
- 입력자 선택: iOS 세그먼트 컨트롤(흰 알약 + 그림자, 다크는 회색 알약).
- 카드 선택: 선택된 칸에 ✓ 동그라미 + 테두리.
- 날짜 옆 '오늘/어제' 빠른 버튼.
- 금액 입력 시 아래에 "12,000원"처럼 콤마 표시, 키보드 '다음/완료' 키.
- 수정창: 아래에서 올라오는 시트 + 손잡이, 바깥 누르면 닫힘.
- 삭제: 목록의 ✕ 즉시 삭제 → 시트 안 '삭제' 버튼, 한 번 더 눌러야 삭제(실수 방지). 삭제 함수(`handleDelete`)는 그대로.
- 하단 탭바: iOS처럼 반투명 흐림.
- 접힘 줄 펼칠 때 부드러운 등장, 시트 슬라이드 업. '동작 줄이기' 설정이면 애니메이션 끔.
- layout: `viewport-fit=cover`(노치·홈바 안전영역), 라이트/다크 `theme-color`, 홈 화면 앱 모드 메타.
- 진동(햅틱): iPhone Safari 웹은 진동 API를 지원하지 않아 넣지 않음.
